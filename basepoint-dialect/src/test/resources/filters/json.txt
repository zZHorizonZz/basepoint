A key of a JSON object equals a text.
filter labelled: labels.env = prod
rows: 1, 3

A key of a JSON object is not equal to a text, and the objects without the key do not match.
filter labelled: labels.env != prod
rows: 2

A key of a JSON object matches a pattern.
filter labelled: labels.env = "p*"
rows: 1, 3

:* on a key matches the objects that have it.
filter labelled: labels.env:*
rows: 1, 2, 3

: with a key on a column matches the objects that have the key.
filter labelled: labels:team
rows: 1, 2

NOT matches the objects without the key, and NULL.
filter labelled: NOT labels:env
rows: 4, 5, 6

A number in an object compares as text.
filter labelled: labels.replicas = 3
rows: 6

Keys combine with OR.
filter labelled: labels.team = core OR labels.env = dev
rows: 1, 2
