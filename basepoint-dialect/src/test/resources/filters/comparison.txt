A string equals.
filter orders: state = "OPEN"
rows: 1, 2, 5

An unquoted word is a string.
filter orders: region = EU
rows: 1, 3

Not equal leaves out the rows where the column is NULL, as SQL does.
filter orders: region != EU
rows: 2, 5

Greater than a number.
filter orders: total > 150
rows: 3, 5

At least a number.
filter orders: total >= 150
rows: 1, 3, 5

Less than a number.
filter orders: total < 80
rows: 4

At most a number.
filter orders: total <= 80
rows: 2, 4

Greater than a negative number.
filter orders: total > -1
rows: 1, 2, 3, 4, 5

A number in exponent form.
filter orders: total < 1e2
rows: 2, 4

A number beyond a long matches no row of an int column.
filter orders: total = 99999999999999999999
rows:

A number with a fraction compares with a decimal column.
filter products(sku): price > 4.25
rows: MUG, PLATE

A number with a fraction equals a stored decimal.
filter products(sku): price = 3.25
rows: CUP

A whole number compares with a decimal column.
filter products(sku): price < 5
rows: CUP, MUG

true matches a true boolean.
filter orders: paid = true
rows: 1, 3

false matches a false boolean, and not NULL.
filter orders: paid = false
rows: 2, 5

A value of no row matches no row.
filter orders: state = "NONE"
rows:
